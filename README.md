# Frog jumping

Data on frog jumping from the Calaveras County Jumping Frog Jubilee.

## Data source

Credit to Jenny Bryan for the original data and cleaning work:
<https://github.com/jennybc/frogs>

## Contents

- `CalaverasData.xls` — raw data
- `import.R` — imports and cleans the data, generates a `frog_id` per jump series
- `frogs.parquet` — cleaned data in parquet format
